# Statistical Project - NHANES 2021-2023

This repository contains the phase-by-phase statistical analysis project for the Statistics course.

## Dataset
The data is sourced from the CDC NHANES 2021-2023 survey. Raw data files are not included in this repository due to size limits. See `data/README.md` for download and preprocessing instructions.

## Structure
- `src/`: Java source code for data loading, merging, analysis, and plotting.
- `figures/`: Generated plots.
- `reports/`: PDF reports for each phase.
